# Frontend Roadmap

This roadmap organizes the frontend before building out large screens. The initial priority is having structure, clear API contracts, and a stable workflow.

## Objective

Build a React administrative application connected to the `backend-preschool` backend, keeping frontend and backend as separate repos.
